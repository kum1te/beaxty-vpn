# Beaxty VPN — development archive

> **Do not use this branch or any binary built from it.**

The `main` branch is intentionally empty of the application source because Beaxty VPN is undergoing a security and reliability rewrite. It is not a release, it is not production ready, and it must not be used to protect personal or organizational traffic.

Active development continues in [`dev`](https://github.com/kum1te/beaxty-vpn/tree/dev). The current findings and the repair plan are documented there in [`docs/AUDIT_2026-09-26.md`](https://github.com/kum1te/beaxty-vpn/blob/dev/docs/AUDIT_2026-09-26.md).

Do not download or redistribute old release artifacts while this notice is present. A stable `main` branch and release will be restored only after the security review, fixes, cross-platform testing, and release checks are complete.
